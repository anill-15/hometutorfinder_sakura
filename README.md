# Home Tutor Finder

A simple web app that connects **students with tutors**.

Students can find tutors, create requirements, send requests, manage favourites, and leave reviews.  
Tutors can manage their profiles, availability, applications, and requests.  
Admins can manage users, verify tutors, and review reports.

## Features

### Students
- Register and log in
- Search and filter tutors
- View tutor profiles
- Add tutors to favourites
- Create learning requirements
- Manage tutor requests
- Leave reviews and ratings
- View notifications

### Tutors
- Register and log in
- Create and edit profile
- Set availability
- Browse student requirements
- Apply to requirements
- Manage requests
- View ratings and reviews

### Admin
- Manage users
- Verify tutors
- Manage requirements and requests
- Review reports

## Tech Stack

- React
- Vite
- React Router
- JavaScript
- CSS
- LocalStorage
